The honest summary. The full model clearly beats guessing, but it is not reliably better than a simple model that only knows each team's win %. Its average champion log loss is {{ '%.2f' | format(full.champ_log_loss) }} vs {{ '%.2f' | format(rec.champ_log_loss) }}; a bootstrap over seasons puts the difference anywhere from {{ '%+.2f' | format(c1.lo) }} to {{ '%+.2f' | format(c1.hi) }} (95% interval), which includes zero. At the series and game level the two are essentially tied. With one champion per season, {{ full.seasons }} seasons is simply not enough data to separate models that are this close.

Predicting the champion

Brier score: squared error of the probabilities summed over the 16 playoff teams (0 is perfect, lower is better). Log loss: −ln(chance given to the actual champion), averaged (lower is better; heavily punishes confident misses). "Best record wins" puts 100% on the best record, so its log loss is infinite whenever it misses.

Limitations

  • Only {{ full.seasons }} test seasons, so champion-level metrics have wide error bars.
  • The "health" features are proxies built from who played, not real injury reports; late-season rest looks like injury.
  • Players are assumed to stay with the last team they played for; there is no injury news after the regular season ends.
  • Betting odds are not compared: no free, legitimate source of historical title odds was found.
  • Playoff experience only counts games since 1996-97 (the start of the data), so early seasons undercount veterans.
  • Games are treated as independent coin flips with fixed probabilities; real series have momentum, adjustments and injuries.
